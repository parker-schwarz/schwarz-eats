# Schwarz Eats — Meal Planner App

Mobile-first weekly meal planning app for Parker & Natalie. Swipe through HelloFresh recipes, build a shopping list, and email it to both of you.

## Files
- `index.html` — the full app (single file, self-contained)
- `recipes.js` — 9,000+ HelloFresh recipes with images and ingredient data (auto-generated by the scraper)

## How to use

1. Open the app and enter your PIN
2. Set your protein and dish type preferences, then tap **Start Swiping**
3. Swipe **right (👍)** to pick a meal, **left (👎)** to skip
4. Use the cuisine and time filter chips to narrow the deck
5. Tap the **"X picked"** badge to review your selections
6. Tap **Shopping list →** to see all ingredients combined and categorized
7. Check off items you already have at home
8. Tap **Send to email →**, add recipient addresses, and send — everyone gets the meal plan + shopping list

## Setup (one-time)

### PIN
The default PIN is `2580`. Change it anytime from the preferences screen (gear icon → Change PIN). The PIN is stored as a SHA-256 hash in `localStorage` — it is not in plaintext anywhere.

### n8n webhook (sends the email)
The app posts to an n8n webhook at `parkerschwarz.app.n8n.cloud`. To update the webhook URL, find this line near the top of the `<script>` section in `index.html`:
```js
const N8N_WEBHOOK = "https://parkerschwarz.app.n8n.cloud/webhook/schwarz-eats-meal-plan";
```

The webhook payload includes:
- `emails` — array of recipient addresses entered in the app
- `subject` — meal plan subject line
- `meals` — numbered list of picked meals with recipe card links
- `shopping_list` — items to buy (with quantities where available)
- `have_list` — items already checked off
- `meal_count`, `item_count` — counts for the email summary

### Email recipients
Recipients are added and saved inside the app on the send screen. No hardcoded email addresses in the source.

### Deploy to GitHub Pages
1. Push `index.html` and `recipes.js` to a public GitHub repo
2. Go to **Settings → Pages → Source → Deploy from branch → master → / (root)**
3. Your app will be live at `https://YOUR_GITHUB_USERNAME.github.io/REPO_NAME/`
4. Bookmark on both phones and add to home screen for an app-like feel

## Updating recipes
Re-run the scraper pipeline from the `scraper/` directory:
```
node scrape-hellofresh.js
node deduplicate.js
node enrich-quantities.js
```
This regenerates `recipes.js` with the latest HelloFresh catalog.
